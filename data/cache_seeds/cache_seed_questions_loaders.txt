CACHE SEED QUESTIONS - TO BUILD
================================
30 seed questions for testing the verified-answer cache (Week 7, H3).
Each seed will be asked first so its answer is stored in the cache. Then your
variant question is asked, and we check whether the cache reuses that answer.

  15 seeds need a PARAPHRASE  -> the cache SHOULD reuse the stored answer
  15 seeds need a NEAR_MISS   -> the cache must NOT reuse the stored answer

WHAT TO WRITE
-------------
Fill in only the lines after "PARAPHRASE:" or "NEAR_MISS:" (and NEAR_MISS_ANSWER:).
Each seed's TASK line says which one is required. The other one is optional:
filling it too gives the test more data. Leave unused fields empty.

PARAPHRASE - same question, different words. The correct answer must be EXACTLY
the same as the seed's gold answer.
  - Change the wording and sentence order; use synonyms, a shorter or more casual
    phrasing, or a different level of detail.
  - Keep every fact that decides the answer: names, IDs, dates, regions, numbers.
  - Do not just swap one word; make it read like a different person asked it.

NEAR_MISS - looks like the seed but has a DIFFERENT correct answer.
  - Change one detail that changes the answer: a priority level, region, date,
    week number, threshold, product, customer, or which fact is asked for.
  - Best near-misses ask about another fact in the SAME source document (open the
    SOURCE file below), so the wording stays very close to the seed.
  - Keep as much of the seed's wording as possible; small changes are the point.
  - On NEAR_MISS_ANSWER, write the correct answer from the source document, or
    "not in documents" if the document does not answer it.

Example (seed qst_0104, buddy time for a converted contractor = 1 hour/day for 2 weeks):
  PARAPHRASE: For contractors converting to full-time, how long should their buddy
              spend with them each day in the first two weeks?
  NEAR_MISS:  How much time is a new hire buddy expected to spend per week by
              week 6 when a long-term contractor converts to a full-time employee?
  NEAR_MISS_ANSWER: 1-2 hours per week

RULES
-----
  - Keep each answer on one line (it can be long). Do not edit the other lines.
  - Do not look at or use questions from the test split.
  - 6 seeds have a WRONG or PARTLY CORRECT cached answer (see VERDICT). Write
    variants for them the same way; they measure how often the cache repeats a
    wrong answer.
  - When done, save the file as cache_seed_questions_loaders_complete.txt in
    this folder (data/cache_seeds/).

Seeds come from the dev (22) and val (8) splits. Each seed's source document is
different. CACHED ANSWER is what the pipeline answered in the latest run
(adaptive retriever, Llama expander); it is what the cache will store.
